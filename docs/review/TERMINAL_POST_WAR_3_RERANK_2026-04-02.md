# Terminal Post War 3 Rerank 2026-04-02

## Purpose

Choose the next real architecture battlefield after War 3.

## Current Read

War 3 materially changed the terminal stack.

The old default enemies are no longer strong enough to drive the queue by
momentum:

- publication
- runtime shell
- aggregate session object shape
- public root identity

Those all improved enough that they no longer dominate first-glance read.

## Strongest Remaining Question

The strongest remaining terminal question is now narrower and more deliberate:

- should `TerminalCore` remain the dominant field inside `TerminalSession`, or
  should a future design make it the more fully sufficient library object?

That is real, but it is not ready for implementation-first cutting.

## Repo-Wide Ranking

From the new baseline:

1. Terminal deeper object-model design
   - only if we are ready to explicitly design `TerminalCore` vs
     `TerminalSession`
2. Renderer / scene / publication convergence
   - now more likely to beat another speculative terminal cut
3. Tactical correctness lanes only with live repros

## Decision

Do not continue War 3 by momentum.

The next move should be either:

1. open a new deliberate terminal design war around `TerminalCore` sufficiency,
   or
2. rerank the whole repo and pick a different battlefield if it now beats that
   design question.
