# Deferred Focuses

This folder holds former repo-wide or long-running focus lanes that are no
longer the active default campaign.

Use it for:

- deferred focus summaries
- pause-state notes
- pointers back to owning technical authority when a lane is resumed

- current default priority
- live architecture authority
- active execution queues
