# Terminal Terminfo Reference

This directory holds reference terminfo dumps used for comparison during
terminal compatibility work.

These files are not product-owned runtime assets.

- shipped Zide terminfo source lives at `terminfo/zide.terminfo`
- packaging compiles that source into bundled terminfo artifacts
- reference dumps here exist to document and compare peer capability surfaces

Current reference files:

- `xterm-256color.info`
- `xterm-kitty.info`
